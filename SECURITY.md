# Security Policy

## Supported versions

Security fixes are currently provided for the latest released OpenBeats version.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk.

Use GitHub's private vulnerability reporting feature for this repository when available. If private reporting is not available, contact the repository owner privately before publishing technical details.

Please include:

- the affected OpenBeats version
- the affected Windows and DaVinci Resolve versions
- clear reproduction steps
- the expected and observed behavior
- any relevant logs, with personal paths or media names removed where possible

OpenBeats runs a local background agent and processes media locally. Reports involving installer behavior, local file handling, command execution, or Resolve/agent handoff are especially useful.
