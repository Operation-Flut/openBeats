# Changelog

All notable changes to OpenBeats are documented here.

## 0.1.0

Initial public release.

### Added

- DaVinci Resolve 21.1+ Free and Studio integration.
- Resolve Free-compatible Lua-to-agent handoff without UIManager.
- External Kivy settings window.
- Audio-track selection.
- Music Tempo, Drum Beat, and Onset detection modes.
- Balanced, Clean, Drums, Dense, and Bars presets.
- Sensitivity, marker interval, accuracy, transient snap, and minimum-gap controls.
- Configurable marker color and marker name.
- Local librosa analysis with bundled ffmpeg decoding.
- Automatic cleanup and replacement of previous OpenBeats markers in the analyzed range.
- Windows per-user installer and background-agent startup.
- CI, packaging checks, and tagged GitHub Release workflow.
